## Что это за проект
Движок мультилендинга для юридической антикризисной службы (Москва и МО).
Партнёры: Рамис + Ильдар (автоматизация, продукт, инфра) × Иван Спирин (юридическая экспертиза).
Стартовый сегмент: горячий кризис бизнеса — арест счетов, налоговые проверки, ФСПП, субсидиарка.
Модель: один движок, посадочные генерируются из конфига `content/landings.ts`. Новая боль = новый объект в конфиге, не новый код.

## Стек
- Next.js 15 (App Router, TypeScript)
- Деплой: Coolify / Docker / VPS (output: 'standalone')
- AI-квалификатор: n8n (webhook + Claude API), фронт ходит только в свой `/api/lead`
- Аналитика: Яндекс.Метрика

- ОБЯЗАТЕЛЬНО предупреждай меня перед опасными/необратимыми действиями: удаление файлов, git force-push, изменения в продакшене, сброс истории, любые деструктивные команды.

  без ожидания отдельной команды. Если remote не настроен — скажи явно, не молчи.
- ОБЯЗАТЕЛЬНО веди `WORKLOG.md` в корне проекта. В конце каждой задачи дописывай туда новую запись в конец файла:

## Дизайн
Технологичный премиум для юридической ниши. Не должно читаться как шаблон или «собрано за вечер».
- Тёмная база: глубокий графит `#0E0F12` (не плоский чёрный)
- Один благородный акцент: золото/латунь `#C9A227`
- Serif с характером на заголовках, чистый гротеск на теле
- Много воздуха, пустота = премиум, один смысловой акцент на экран
- НОЛЬ стоковых картинок (рукопожатия, молотки судьи, весы). Вместо этого — типографика, тонкие линии, аккуратная сетка, абстрактная графика
- Дорогие ненавязчивые микроанимации, с уважением к prefers-reduced-motion
- Дизайн-токены держать в одном месте (перекраска в globals.css)
- Дизайн-инструменты: плагин ui-ux-pro-max, frontend-design, magic MCP — использовать по назначению

## Что нельзя ломать
Вся логика движка: SSG, generateStaticParams, generateMetadata, `/api/lead`, Яндекс.Метрика с целями, JSON-LD, sitemap, robots. При изменениях дизайна меняем только презентационный слой.

## Env-переменные (Coolify)
- `NEXT_PUBLIC_METRIKA_ID` — ID Яндекс.Метрики. Обязательно отметить как Available at Buildtime, иначе Метрика молча не включится.
- `NEXT_PUBLIC_SITE_URL` — для sitemap/robots/канонических. Тоже Buildtime.
- `N8N_WEBHOOK_URL` — endpoint n8n для приёма заявок. Server-side, не публичный.
Проект должен собираться и работать без заданных env (Метрика и n8n просто отключаются, билд не падает).

Домены, аккаунты Метрики, Директа, VPS — на почтах с доступом у команды, не «внутри» ООО брата-юриста. Бренд в текстах не привязывать жёстко к конкретному юрлицу, чтобы можно было сменить ООО без переделки.
